Gestión de Vacantes

Activa, desactiva o crea vacantes. Descarga y sube el archivo al servidor para publicar.

¿Cómo funciona?

  1. Usa los toggles para activar o desactivar vacantes. Usa "+ Nueva vacante" para crear una.
  2. Cuando termines, haz clic en "Descargar vacantes-estado.js".
  3. Sube el archivo descargado al servidor (misma carpeta que index.html), reemplazando el anterior.
  4. Refresca la web pública para verificar los cambios.
